# ⏰ Digital Clock Web Application

A simple and elegant **real-time digital clock web app** that displays the current date, time, and timezone, along with motivational and Islamic reflections on time.

---

## 🌐 Navbar Structure

- **Home**
- **Link**
- **Search Bar**

Clean and minimal navigation for a smooth user experience.

---

## 🕰️ Features

- 📅 Displays **current day and date**
- ⌚ Shows **live current time** (hours, minutes, seconds, milliseconds)
- 🌍 Displays **UTC time**
- 🔄 Updates automatically in real time
- 💡 Includes **motivational and Islamic quotes** about time

---

## 🖥️ UI Display Example

- **Today is:** Saturday  
- **Current time is:** 6 PM : 12 : 550  
- **Timezone:** UTC  

### Inspirational Quotes:
> *"The clock is ticking—what are you doing with your time?"*  
> *"Time, a Gift from Allah – Use It Wisely."*

---

## 🛠️ Technologies Used

- **HTML5** – Page structure  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Real-time clock functionality  

---

## ⚙️ How It Works

- JavaScript `Date()` object is used to fetch:
  - Current date
  - Local time
  - UTC time
- Time updates automatically using intervals
- Clean UI for readability and focus
